# core/ 领域逻辑核 (Domain Logic Core)

> **原则：纯逻辑、零视觉、100% 确定性**

## 职责定位
- 战局主仿真循环、Tick 时钟与状态快照（`sim/`）
- 战斗判定与伤害结算公式、Buff/状态机（`combat/`）
- 技能机制、弹道数学轨迹、冷却消耗（`skills/`）
- 英雄与小兵等实体数值定义（`entities/`）
- 地图静态几何、防御塔/基地坐标与阻挡边界（`map/`）

## 开发铁律
1. **严禁继承任何 Node 节点**：所有脚本必须是纯 `RefCounted` 或纯数据结构。
2. **严禁调用视觉与引擎节点 API**：严禁出现 `Node3D`, `Control`, `Mesh`, `Material`, `GPUParticles3D`, `get_tree()`。
3. **确定性与无头可测**：任何逻辑必须支持在没有窗口的单测中以 1000 倍速纯计算运行并验证。
