# view/ 3D 表现层 (3D Presentation View)

> **原则：只读消费快照，负责平滑插值、动画分发与打击反馈**

## 职责定位
- 相机系统：刚性跟随、平滑缩放、震屏（`camera/`）
- 单位装配：英雄多部件拼接、骨骼动画驱动（`units/`）
- 战斗表现：普攻弹道飞行动画、打击受击反馈、飘字表现（`combat/`）
- 范围指示：常驻金色普攻环、技能施法范围环、移动落点呼吸环（`indicators/`）
- 场景表现：泉水光环、防御塔攻击光柱（`environment/`）
- 视觉特效：着色器预热、特效节点挂接（`effects/`）

## 开发铁律
1. **只读驱动，严禁改写数值**：View 只有读快照的权限，严禁私自改动血量或触发游戏结算。
2. **高频视觉必须走对象池**：弹道飞弹、受击粒子、伤害飘字严禁在战斗中动态 `.new()` 和 `queue_free()`，必须经由 `infra/pool/` 池化复用。
