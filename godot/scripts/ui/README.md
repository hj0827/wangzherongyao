# ui/ 2D 界面交互层 (2D User Interface)

> **原则：单向数据展示，收集玩家意图，严禁越级控制 3D 实体**

## 职责定位
- 通用样式与主题（`common/`）
- 战局主 HUD：虚拟摇杆、技能轮盘瞄准、小地图、头顶血条蓝条（`hud/`）
- 全屏主界面：主菜单、选人室、结算面板、立体视差动态背景（`screens/`）
- 弹窗面板：战局暂停、断线重连对话框（`popups/`）

## 开发铁律
1. **单向意图流**：UI 控件（按钮、摇杆）只能向输入层派发意图（Intent），绝不允许在按钮回调中直接命令 3D 英雄播放动画或执行逻辑。
2. **纯粹性**：UI 仅负责数据的投影与交互事件收集。
