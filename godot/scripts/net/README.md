# net/ 网络与同步层 (Networking & Synchronization)

> **原则：客户端抗抖动缓冲，服务端权威调度，协议统一编解码**

## 职责定位
- 客户端会话：Jitter Buffer 缓冲队列、输入提交（`client/`）
- 服务端会话：输入收集与合并、状态广播（`server/`）
- 协议定义：包头、指令枚举、序列化/反序列化（`protocol/`）
- 局域网发现：UDP 广播与房间心跳探查（`discovery/`）

## 开发铁律
1. **抗抖动与解耦**：快照回放按服务端时钟驱动，网络抖动只影响缓冲深度，不影响插值匀速性。
2. **协议安全**：所有客户端输入在服务端必须经过合法性校验。
