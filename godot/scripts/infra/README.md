# infra/ 基础设施与底层支持 (Infrastructure & Engine Core)

> **原则：零即时分配、统一硬件适配、根治真机卡顿的生命线**

## 职责定位
- **全局对象池（`pool/`）**：粒子池、飘字池、弹道飞弹池。负责战前预热实例化，战中 `acquire()` / `release()` 复用，彻底消除移动端 GC 掉帧。
- **输入适配（`input/`）**：将 PC 键鼠与移动端触控摇杆统一抽象为战局 Action 向量。
- **音频服务（`audio/`）**：全局音效与背景音乐的实例管理与循环控制。

## 开发铁律
1. **零动态 new**：高频短期产生的视觉/音效对象必须注册进对象池。
2. **纯粹复用**：对象回收时必须彻底重置 Transform、透明度与材质参数，杜绝脏状态残留。
