## 0. 本项解决的两个问题

### 问题 1：完全没有硬控

差距文档 §3.3：`sim` 里只有 `slow/haste/shield/cc_immune` 四种状态，
**没有眩晕、击飞、沉默、定身**。grep `stun/knockup/silence/frozen` 在逻辑层 0 命中。
"王者一个刺客没有硬控链是不可想象的" —— 当前墨鸦爆发再高也"按不住"目标。

### 问题 2（更严重）：`cc_immune_timer` 是死字段

改造前全仓搜索显示：
- `skill_system.gd:117` 写入（evade 给免疫）
- `skill_system.gd:254` 写入（净化给免疫）
- `match_sim.gd:772` 递减
- 测试断言它 `> 0`

**但没有任何生产代码读它。** 也就是说"免疫"完全是装饰：
玩家开了净化、刺客开了匿踪，减速照吃不误，硬控（如果存在）也挡不住。
这是仓库反复警告的"字段在、计时在走、没人收账"形态。

现在唯一的读取点收在 `ControlRules.is_immune()`，并有变异 C4/C5 专门守它。

## 1. 行动矩阵（这是本项的核心契约）

| kind | 禁移动 | 禁施法 | 禁普攻 | 附加 |
| --- | --- | --- | --- | --- |
| `stun` 眩晕 | ✓ | ✓ | ✓ | |
| `knockup` 击飞 | ✓ | ✓ | ✓ | 强制位移 2.2m |
| `silence` 沉默 | ✗ | ✓ | ✗ | |
| `root` 定身 | ✓ | ✗ | ✗ | 仍可转向 |

**两条刻意的例外**（写进代码注释，免得后来者以为是漏判）：

1. **转向不受限制** —— 定身/眩晕时仍可调整朝向。连朝向都锁死，
   手感会变成"游戏卡住了"而不是"我被控住了"。
2. **召唤师技能不受控** —— 否则净化永远解不开自己身上的控，这张牌就废了。

### 变异验证抓出的 5 个真实缺陷

1. **C4/C5 —— 免疫是死字段**（本项最重要）。修法：把唯一读取点收进 `ControlRules.is_immune()`。
2. **C11 逃逸 —— 文本守卫会互相掩护**：`has_live_line(src, 'skill.get("control", {})')`
   在两个分支里都出现，删掉其中一个仍然绿。**必须用行为测试**（真放一次技能，断言目标真被控）。
3. **C13 —— 净化只清减速**，而描述写的是"解除所有控制"。玩家交了净化还被眩晕按在地上。
4. **C8/C15 —— bot 被控时完全不作为**。这看似正确，实际把**净化**这张牌废掉了：
   净化的全部意义就是在被控时使用。修法：去掉提前 `continue`，让召唤师技能不受控。
5. **C16 —— 只测函数不测接线**。`control_status_caption` 算得再对，
   `role_text` 不调用它，玩家就永远看不到。这类"函数在、测试绿、生产引用 0"是仓库老毛病。

## 7. ⚠️ 实测：本项让对局时长明显变短（必须报告）

`pacing_report --samples=2 --comps=2 --limit=1200 --mode=team`（4 样本）：

| 指标 | 项 3 后 | **项 4 后** |
| --- | --- | --- |
| 分出胜负 | 4/4 | 4/4 |
| 时长中位数 | 11m01s | **8m04s** |
| 落在 8–12 分钟带 | 100% | **50%** |
| 最短局 | — | **4m23s**（碾压） |
| 结束时英雄中位等级 | 7 | **5** |
| 事件峰值 / 上限 | 24/32 | 24/32 |

**归因**：硬控让集火与越塔更致命，对局节奏整体前移。这不是 bug，
但**明显偏离 8–12 分钟的标定带**，且出现了 4 分钟碾压局（说明雪球效应偏强）。

**结论**：项 4 不能单独定稿节奏。这与项 6 §6（胜率偏向）是同一类问题——
需要在 6b「对局公平性」里连同首塔时刻、雪球效应一起标定。

**项 3.5 事件压力**：峰值 24 / 上限 32 = **1.33×**，**未达验收要求的 1.6× 余量**。
新增 `projectile_spawned` / `projectile_hit` 两类事件后余量进一步收紧，需要关注。
