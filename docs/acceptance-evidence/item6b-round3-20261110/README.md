## 1. 核心成果：CS 偏向从"恒定 +19"降到"±4 抖动"

这是本轮最有力的证据，比胜率更能说明问题。

| 指标 | 修复前 | **修复后** |
| --- | --- | --- |
| 8 个 seed 在前 300 秒的 CS 差（红−蓝） | **恒为 +19**（5 个 seed 完全一致） | 0, −1, −4, 0, −1, −2, −1, 0 |
| 镜像局胜率（12 局） | 红 10 / 蓝 0 | 红 **9** / 蓝 **3** |
| 单局击杀对比 | 差距大 | **49:52 / 54:54 / 48:54 / 55:54** |
| 单局 CS 对比 | 约 78:104 | **104:102 / 107:118 / 107:110 / 115:121** |
| 5v5 时长中位数 | 8m04s | **12m22s** |

**关键判读**：修复前"seed 完全不影响 CS 差"说明那是纯结构性的；现在 CS 差随 seed 在 ±4 内抖动，
说明**结构性偏向已经消除**，剩下的是对局内正常波动。

胜率仍是 3:9，但单局击杀 54:54、CS 104:102 这种数据说明**双方实力已持平**，
胜负只由毫厘之差决定 —— 这与"一方系统性碾压"是完全不同的性质。

## 2. 根因与修法（本轮实质突破）

### 2.1 定位手段：逐帧对称性探针

写 `probe_symmetry_find.gd`：每 tick 把蓝方英雄位置与"红方同名英雄位置的镜像"比对，
直接报出**第一处偏差出现在哪一帧、哪个实体、差多少**。

它立刻指出：**第 0 tick 就偏 0.2~0.4m**，且只出现在边路（mid 完全对称）。

### 2.2 根因：路径点间距不均，固定索引/固定弧长都会落错点

边路相邻路径点间距**从 8.94m 到 16.0m 不等**：

| 位置 | 到自家基地端点的弧长 |
| --- | --- |
| top `idx=1` | 12.65m |
| bottom `idx=13` | **8.94m** |
| bottom `idx=12` | 24.94m |

- 旧实现用**固定索引**（`idx=1` / `size-2`）→ 蓝方刺客 `idx=1`（距自身 4.52m），
  红方 `idx=13`（距自身 16.09m）
- 我第一版改成**固定弧长阈值 12m** → 蓝方 `idx=1`（4.52m），红方 `idx=12`（**29.55m**）
- 两种都会落进不同的离散点，**差 4~25m**

### 2.3 修法：取"离起步落点最近的路径点"

`_index_for_arc(path, entity_pos, from_head)` —— 出生点本身严格点对称，
所以"最近的路径点"也对称。修后两侧到首个 waypoint 的距离：

| 英雄 | 蓝方 | 红方 | 差 |
| --- | --- | --- | --- |
| tank | 20.83 | 21.10 | 0.27 |
| archer | 17.21 | 16.27 | 0.94 |
| assassin | 20.47 | 16.09 | 4.38 |
| blade / mage（mid） | 21.43 / 26.17 | 21.43 / 26.17 | **0** |

刺客残余 4.38m 是**路径点离散化的固有极限**（两侧最近点分属不同间距的段），
已在测试注释写明，阈值定 6m 而非强行收紧。

## 3. 被证伪的方案（记下来免得重试）

### 3.1 让红方走镜像路（top↔bottom）—— 不可行

点对称确实把 top 映射到 bottom，看着很合理。但实测：

1. `bottom` **不是** `top` 的严格镜像 —— 逐点偏差**恒为 4.0m**（采样点错位）；
2. 镜像路的 `idx=1` 落在**蓝方基地侧**，红方起点被甩到 **120m 外**。

### 3.2 一个意外但极有价值的观测

镜像路那版（红方起点 120m 外）跑出来是 **蓝方 10/10 全胜**。
这反证了：**胜负完全由起步位置决定**，不存在"红方有神秘优势"。
它把"偏向"从玄学变成了可测量的几何量 —— 这是本轮能修好的前提。

## 4. 新增守卫（`test_fairness.gd` 5 → 8 条）

| 测试 | 作用 |
| --- | --- |
| `test_top_and_bottom_lanes_are_equal_length` | 两条边路等长、等外接半径（**不断言严格镜像**，实测差 4m，断言了会假红） |
| `test_hero_entry_distance_is_symmetric_across_sides` | 两侧到首个 waypoint 差 < 6m（开发中立刻抓出 25m 的刺客偏差） |
| `test_mirror_cs_gap_stays_small_across_seeds` | **6b 核心回归**：2 个 seed 的 CS 差 < 12（修复前恒为 19） |

用"CS 差"而非"胜率"做守卫的理由：胜率要跑满整局、样本小、噪声大；
CS 差 300 秒就能测，且修复前是**恒定值**，判据非常稳。
