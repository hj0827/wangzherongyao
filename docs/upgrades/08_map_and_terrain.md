# 08 · 地图地形与三线攻防升级

本模块以《王者荣耀》的峡谷结构为参照，把原先「一条中路 + 两座塔」的平面地图升级为
**三线推进 + 分塔解锁 + 野区资源 + 河道首领 + 草丛视野 + 回城补给 + 高地双子塔/水晶护盾 +
河道之灵/传送阵 + 草丛进出反馈** 的完整战场。
模拟层仍是 30Hz 确定性逻辑，表现层只读快照，所有地图点位统一由 `MapLayout` 提供。

## 关键规则

- **防御塔**：每路每队外/内/高地三座，标准局 18 座，单挑局 6 座。外塔可打；内塔需外塔已毁；
  高地塔需内塔已毁；任意一路高地塔倒下，该队基地才可被攻击。
- **前期保护**：开局 180 秒内防御塔伤害减半，降低越塔滚雪球。
- **守塔逻辑**：塔优先攻击小兵；敌方英雄在塔下攻击己方英雄时强制转火 3 秒。
- **兵线**：每波 3 兵（近战/近战/远程），每三波近战换炮车；高地塔倒下后该路改出超级兵；
  生命/攻击随波次成长。
- **野区**：四座镜像营地（霜狼/赤狼），击杀获得 60 秒红/蓝 Buff；蓝 Buff 技能冷却 ×0.8，
  红 Buff 普攻伤害 ×1.12；70 秒刷新。
- **首领**：暴君与主宰分居两侧河道入口，2:00 首刷、每 3:00 刷新；击杀方全队获得 60 秒 ×1.12 增伤。
- **高地双子塔**：每队基地前左右各一座（独立 `guard` 实体，不占用 18/6 座防御塔计数），
  需先拆掉该路高地塔才可攻击；双子塔全部倒下后基地才可被攻击。
- **水晶护盾**：基地暴露时按存活双子塔数量获得护盾（每座 1200，最多 2400），
  护盾优先吸收伤害；停止受击 6 秒后按 320/秒回充，破盾时广播 `crystal_shield_broken`。
- **河道之灵**：上下河道各一只，0:30 首刷、90 秒刷新；击杀方全队获得 60 秒、半径 16 的
  河道视野揭示（写入快照 `river.reveals`，经过视野过滤后按队伍下发）。
- **传送阵**：河道两端成对分布，站上己方传送阵按 `T`/点传送键引导 2.5 秒，
  完成后落到对岸；冷却 45 秒，移动/普攻/施法/回城/受击都会打断。
- **视野**：英雄 14、小兵 8、防御塔 11、基地 15；草丛内敌人需贴近 3.2 或出手才会暴露；
  墙体阻挡视线；建筑永久可见；河道之灵的揭示区可临时穿透草丛与墙体外的战争迷雾。
- **回城**：按 `B` 或点回城键开始 4 秒引导，完成传回出生点，任何行动或受击都会打断。
- **草丛反馈**：本地英雄进/出草丛时触发 HUD 隐匿提示、镜头焦段 0.92× 平滑过渡与合成进出音效；
  死亡时自动清空隐匿态，避免提示残留。

## 表现与网络

- **地图一致性**：Arena、小地图、情报面板全部从 `MapLayout` 取点，避免「画一套、碰撞另一套」。
- **分塔视觉**：内塔/高地塔逐级放大，未解锁塔显示护盾并降低队伍色饱和度；
  双子塔体型略小于高地塔，未解锁时同样显示锁定护盾。
- **水晶护盾**：基地外覆半透明叠加球泡，随护盾量显隐；破盾播放环形冲击波与粒子。
- **河道交互物**：河道之灵为悬浮发光球体，击杀播放扩散环；传送阵为青色圆盘与图腾，
  引导/完成时在起点与落点各播一次传送特效。
- **草丛反馈**：进出草丛镜头焦段平滑收放（42° ↔ 0.92×），配套合成的高低滑音，
  HUD 中央显示「草丛隐匿」提示；全部走本地表现，不进模拟快照。
- **事件播报**：击杀首领、拿 Buff、高地告破、双子塔倒下、水晶破盾、河道之灵被击杀、
  推塔均生成顶部横幅 + 信息流 + 场景特效。
- **队伍快照**：主机通过 `GameSession.broadcast_team_snapshots()` 为蓝/红双方分别构建
  视野过滤快照，再按队伍发送；guard / 水晶护盾 / 传送状态 / 河道揭示等新字段已加入网络白名单。
- **移动端**：HUD 新增回城键与传送键，`skill_pressed("recall" / "teleport")` 与键盘 `B` / `T`
  共用同一输入意图。
